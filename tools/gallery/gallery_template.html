How to make and maintain these images
  1. Pick a batch tab. Open a new ChatGPT chat for it.
  2. Download the batch's reference sheet (original Heroes 3 art) and attach it, then paste the starter prompt. Both are at the top of each tab.
  3. Send one image's prompt per message. Click any card to copy its prompt; cards marked Not generated yet are the ones still missing.
  4. Save each result as the exact file name shown on the card (for example hero-naruto-uzumaki.png), PNG, without resizing.
  5. Check it: transparent background where the batch asks for one (a painted grey checkerboard is not transparency), facing right for creatures, no text, and readable when shrunk to the in-game size.
  6. To redo an existing image, use the same prompt plus a short note of what to change, and keep the same file name.
  7. Upload the results right here: drop or choose files in the upload box of a tab (they are matched to cards by file name), or use Upload new version on one card. Uploaded images show a green Uploaded tag; Anton's side picks them up from there.
Images are shown and downloaded as the full generated masters (PNG on download). Downloads ask you to confirm each save. The prompts here are the same ones in Anton's vault notes, so a change requested in chat gets updated in both places.
